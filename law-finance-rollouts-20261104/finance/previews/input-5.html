43CODES
44
45Files: table1.prg, table2.prg, tableA1.prg, and tableA2.prg
46
47Each code corresponds to a table in the paper as the file's name indicates.
48Each code is self-contained. They only need to read the data and the Gauss library "optmum".
49
50We implement each SDF or regression method by continuously updated (CU), iterated and two-step (2S) GMM.
51Each one of the three variants is associated to one of the three columns in each table.
52The parameter "n_iter" at the beginning of the code controls which variant to run: 1 for CU-GMM, 2 for 2S-GMM, more for iterated GMM.
53Once a value of "n_iter" is chosen, the code can be run and all the numbers of the corresponding column will be obtained.
54
55The convergence of the estimates and the J statistic should be checked when running iterated GMM.
56To check the evolution of the estimates and the J statistic, simply delete @ in these parts of the code:
57
58@
59 "--------------";
60 "iteration" i ;
61 "j, retcode and theta1'"; x[1,.];
62@
63
64In the output of the two symmetric normalizations, we report an equivalent angle below the estimate in case its value is outside (-pi/2,+pi/2).
