05 / Reproduce

一条命令复现

构题器为零第三方 Python 依赖；Qwen runner 只需 OpenAI-compatible 网关地址与进程环境变量中的临时密钥。

bash · build → validate → run
python3 -m workfactory build \
  --recipe examples/go_sales_reconcile.json \
  --output builds

python3 -m workfactory validate \
  --task builds/GO-T2-001 --write-report

export QWEN_API_KEY='YOUR_TEMP_KEY'
export QWEN_BASE_URL='YOUR_OPENAI_COMPATIBLE_BASE_URL/v1'
python3 -m workfactory run-qwen \
  --task builds/GO-T2-001 \
  --model qwen3.8-max
unset QWEN_API_KEY
