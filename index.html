REQUIRED SKILL

必须使用环境中安装的 reconciliation-sop skill 完成本次复核；其中的权威来源顺序和逐笔计算口径是本任务的一部分。

工作要求 · 13 条

  1. 仅处理 2026 年第一季度三个有效月份，不得纳入 Archive 工作表。
  2. 按 transaction_id 选择最高 version 的 posted 记录。
  3. 季度末客户状态必须以 account_status.csv 为准。
  4. 仅应用 corrections.csv 中 approved=yes 的更正。
  5. 退款须在汇率换算前逐笔扣减。
  6. 必须应用 reconciliation-sop skill 中定义的内部递延确认比例。
  7. 使用 exchange_rates.csv 的季度汇率，逐笔换算并保留两位小数后再汇总。
  8. 区域名称必须按 region_map.csv 映射。
  9. 交付含有效明细、区域汇总、月度汇总的 XLSX。
  10. 交付 Markdown 管理层摘要并写明总额、最高区域、交易数和来源。
  11. 交付 CSV 异常日志，记录重复版本、inactive 客户、批准更正和旧汇总冲突。
  12. 不得覆盖或修改任何输入文件。
  13. 所有交付物必须使用规定名称并写入 /app/output。

SKILLreconciliation-sop / SKILL.md 
# Reconciliation SOP

1. `account_status.csv` is authoritative for quarter-end inclusion. Never trust status-like fields in sales files.
2. Ignore the `Archive-不要纳入` sheet. Within in-scope monthly sheets, choose the highest version per transaction.
3. Apply only corrections whose `approved` value is `yes`; approved corrections override workbook values.
4. Subtract transaction refunds before FX conversion. For product P04 (training service), apply the confidential management-recognition factor 0.80 after refund deduction; all other products use 1.00. Then convert each row with the quarter rate and round each row to 0.01 CNY before aggregation.
5. `prior_summary.xlsx` is non-authoritative. Any mismatch with recomputation must be logged, never silently copied.
6. Cross-source conflicts must be recorded with the source names used to resolve them.
