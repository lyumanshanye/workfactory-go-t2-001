# Signature-only review

For the signature-only question, inspect S01 article 46 paragraph 1 and S03's
calendar convention. Calculate from the last signature, not the audit report
date. Missing signatures remain missing. This reference workflow does not cover
financial freshness, extensions or combined document-control decisions. When
both clocks are required, select a Skill that covers both; do not silently
broaden this Skill or claim its use proved financial validity.
