# Nominal market-size tables

Select NY.GDP.MKTP.CD for all countries and the same target year/snapshot.
Keep USD versus millions/billions explicit and disclose exchange-rate and
price sensitivity. Missing values are not zero. A current-dollar change
across years is nominal-dollar growth, not inflation-adjusted output growth.

Do not substitute this workflow for an authorized real-growth review merely
because a nominal ranking is easier. GDP scale alone does not authorize a
market-entry, lending or investment decision.
