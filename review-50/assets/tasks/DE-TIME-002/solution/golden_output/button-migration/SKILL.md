# 按钮迁移审查

适用于冻结团队合同target_version=5.0.0。先核委托批准版本、观察时点与输入来源；晚到无权便笺不改变批准版本。不从今日在线指南倒推历史版本规则。此Skill只在项目目录使用，不改全局配置或部署服务。

## 决策要点

- 官方4.6已弃用、5.0移除govuk-button--disabled。原生button/input的disabled按属性是否存在判断，不按getAttribute返回值真假；空串和文字false都仍表示存在。
- 原生禁用按钮与导航不是同一语义。v5不支持禁用link；不可操作的入口用静态说明，真正可导航的入口保留href和明确文字，不把灰色样式当阻断。
- 本题状态合同来自原创团队，不是所有GOV.UK服务的通用标准。状态标签/说明、失败保留输入并可重试、忙碌时抑制重复模拟、键盘和窄屏均按合同复测。
- 客户端双击抑制不是服务端幂等；本机成功反馈不是申请提交成功。不要伪称认证、后台已验或发布批准。

## 执行与证据

读取项目提供的S04_状态合同.json。原型可用不同样式，但保留合同DOM标识及操作语义，让此检查器能用于后续同类原型。

```bash
python3 button-migration/scripts/audit_states.py --html prototype.html --contract /app/input_files/S04_状态合同.json --out checks.json
```

依赖Python Playwright和Chromium；本题镜像提供/usr/bin/chromium。其他已安装浏览器可用--browser指定；传空串使用已安装Playwright Chromium，不自行联网下载。检查器包含属性存在性/元素语义和实际浏览器两尺寸回放。失败返回2并保存具体检查；缺依赖/异常应报告未完成，不填pass。

按失败证据修复原型并重跑，核JSON的源/脚本哈希确为当前文件，再同步迁移文档。更换合同或页面ID须同步检查器，不能把检查全部删掉或写恒真。至少实际验证一个错用旧类、一个禁用属性误读和一个失败后无法重试的反例。

输出只是本团队合同的测试证据，不是任意HTML安全扫描器、全WCAG或辅助技术认证。静态属性检查不能替代浏览器交互；两尺寸回放也不代表全部浏览器/设备。服务端、真人研究、辅助技术及上线审批另行交接，不实际联系用户或外发。
