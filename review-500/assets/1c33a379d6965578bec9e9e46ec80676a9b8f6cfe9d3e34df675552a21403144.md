# Domain Audit SOP

1. Treat `facts.csv` as the record authority; `reported_value` is a conflicting legacy field and is never an adjusted result.
2. For each `record_id`, select the greatest integer `version`, then exclude the record unless its selected status is `active`.
3. Apply the category factor: `核心 = 1.10`, `支持 = 1.00`, `观察 = 0.85`. Compute `adjusted_value = round(base_value * factor, 2)` per record before aggregation.
4. Preserve `facts.csv` as `evidence_source`; document every conflict rather than silently choosing a value.
5. Never introduce a record, source, entity, or threshold absent from the supplied workspace.
