# 任务口径与权威源

- 领域：数据分析 / DA1-数据获取与治理
- 场景：你作为数据工程师，需在数据分析场景中对保留周期执行盘点与登记数据源，最终支持多个数据源应按何顺序接入的可追溯决策。

职业分类参考：O*NET 31.0 15-1243.01 Data Warehousing Specialists。职业定义：Design, model, or implement corporate data warehousing activities. Program and configure warehouses of database information and provide support to warehouse users.
此对应关系由本管线按原有二级领域编写，不是 O*NET 官方领域划分；保留原业务角色和任务，不把该职业的任意官方任务强行当成本题。材料与规则仍是旧管线构造的虚构案例，不是官方业务规范。
- `facts.csv` 是明细事实权威源；`reported_value` 是待复核旧报告值，不得直接作为最终结论。
- 同一 record_id 取最高 version，仅纳入 status=active；逐条保留两位小数后汇总。
- 类别调整系数只在 `domain-audit-sop` skill 中定义，必须依据该 skill 计算。
- 领域约束：默认遵循最小权限和用途限定原则
- 领域约束：所有发布数据必须可追溯到来源和处理步骤
