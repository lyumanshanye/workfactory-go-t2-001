# 任务口径与权威源

- 领域：数据分析 / DA5-预测与机器学习
- 场景：你作为业务模型负责人，需在数据分析场景中对分类与回归执行评估区分度、校准度与误差分布，最终支持分组性能差异是否阻止部署的可追溯决策。

职业分类参考：O*NET 31.0 15-2051.00 Data Scientists。职业定义：Develop and implement a set of techniques or analytics applications to transform raw data into meaningful information using data-oriented programming languages and visualization software. Apply data mining, data modeling, natural language processing, and machine learning to extract and analyze information from large structured and unstructured datasets. Visualize, interpret, and report data findings. May create dynamic data reports.
此对应关系由本管线按原有二级领域编写，不是 O*NET 官方领域划分；保留原业务角色和任务，不把该职业的任意官方任务强行当成本题。材料与规则仍是旧管线构造的虚构案例，不是官方业务规范。
- `facts.csv` 是明细事实权威源；`reported_value` 是待复核旧报告值，不得直接作为最终结论。
- 同一 record_id 取最高 version，仅纳入 status=active；逐条保留两位小数后汇总。
- 类别调整系数只在 `domain-audit-sop` skill 中定义，必须依据该 skill 计算。
- 领域约束：阈值必须依据业务成本而非仅依据技术指标
- 领域约束：生产模型必须绑定数据、代码、配置与环境版本
