# 排班约束求解模型说明

## 1. 问题概述

本任务为预防接种门诊的HPV疫苗全员培训与窗口服务联合排班问题。需要在3天×2时段=6个时间槽内，同时满足：
- 3个服务窗口（咨询台C、接种室I、留观区O）每时段最低人员覆盖
- 10名员工各参加恰好1场培训（共3场，分布在3个PM时段）
- 每人每天任务数在[1, 2]区间内

---

## 2. 决策变量定义

### 2.1 窗口分配变量

$$X_{e,t,w} \in \{0, 1\}$$

表示员工 $e \in \{A1..A5, N1..N5\}$ 在时段 $t \in \{D1\_AM, D1\_PM, \ldots, D3\_PM\}$ 是否被分配到窗口 $w \in \{C, I, O\}$。

### 2.2 培训分配变量

$$Y_{e,s} \in \{0, 1\}$$

表示员工 $e$ 是否参加场次 $s \in \{T1, T2, T3\}$ 的培训。

---

## 3. 约束条件映射

### 3.1 窗口覆盖与资质白名单（REQ3/REQ4/REQ5/REQ14/REQ15）

**最低人数约束：**
$$\sum_{e} X_{e,t,w} \geq \text{min\_count}_w \quad \forall t, \forall w$$

**资质白名单约束（排他性）：**
$$X_{e,t,w} = 1 \implies \text{skills}(e) \subseteq \text{allowed\_skills}_w$$

具体映射：
| 窗口 | allowed_skills | 排斥规则 |
|------|---------------|----------|
| C(咨询台) | {Admin} | 禁止 Nursing 技能员工 |
| I(接种室) | {Nursing} | 禁止 Admin 技能员工 |
| O(留观区) | {Admin, Nursing} | 无排斥，两种技能均可 |

### 3.2 全员培训覆盖（REQ6/REQ18）

$$\sum_{s} Y_{e,s} = 1 \quad \forall e$$

每位员工恰好参加1场培训，10名员工全部纳入。

### 3.3 培训容量限制（REQ7）

$$\sum_{e} Y_{e,s} \leq \text{capacity}_s \quad \forall s$$

每场培训教室容量上限为4人。

### 3.4 时间互斥约束（REQ8）

$$\sum_{w} X_{e,t,w} + \sum_{s: \text{time}(s)=t} Y_{e,s} \leq 1 \quad \forall e, \forall t$$

同一时段内，每人最多承担1项任务（窗口或培训）。

### 3.5 培训时间一致性（REQ9/REQ13）

$$Y_{e,s} = 1 \implies e \text{ 在时段 } \text{time}(s) \text{ 参加培训}$$

T1→D1_PM, T2→D2_PM, T3→D3_PM，不可偏移。

### 3.6 每日任务上下限（REQ10/REQ16）

$$1 \leq \sum_{t: \text{day}(t)=d} \left(\sum_{w} X_{e,t,w} + \sum_{s: \text{time}(s)=t} Y_{e,s}\right) \leq 2 \quad \forall e, \forall d$$

每人每天至少1个时段任务（不闲置），最多2个时段任务（保障休息）。

### 3.7 数据有效性（REQ11/REQ12）

所有出现的员工ID和时间槽ID必须存在于输入数据中。

---

## 4. 可行性分析

### 4.1 资源总量估算

| 维度 | 数值 |
|------|------|
| 员工数 | 10人 |
| 时段数 | 6个（3天×2） |
| 理论最大人-时容量 | 10×6 = 60 人-时 |
| 受REQ16约束的有效容量 | 10×3天×[1,2]/天 = [30, 60] 人-时 |
| 窗口最低需求 | 3窗口×6时段×1人 = 18 人-时 |
| 培训需求 | 10 人-时 |
| 最低总需求 | 18 + 10 = 28 人-时 |

**结论：** 有效供给下限30 ≥ 最低需求28，且余量2人-时可灵活分配。问题可行。

### 4.2 培训分配可行性

- 3场培训总容量 = 4+4+4 = 12 ≥ 10人需要
- 分配方案：T1=4人, T2=3人, T3=3人（总计10人）
- 各场均未超容量

### 4.3 每时段窗口覆盖可行性

**AM时段（无培训）：** 10人全部可用于窗口。5名Admin中3人→C、2人→O；5名Nursing中3人→I、2人→O。每个窗口≥1人 ✓

**PM时段（有培训）：** 扣除培训人员后，剩余6~7人。其中至少有2名Admin和2名Nursing可用于窗口分配：
- D1_PM: 剩余6人（3 Admin + 3 Nursing），分配 C=2, I=2, O=2 ✓
- D2_PM: 剩余7人（3 Admin + 4 Nursing），分配 C=2, I=2, O=3 ✓
- D3_PM: 剩余7人（4 Admin + 3 Nursing），分配 C=3, I=2, O=2 ✓

### 4.4 每日任务数可行性

每人每天固定分配：AM窗口(1) + PM窗口或培训(1) = 2个任务，恰好在[1,2]范围内。

---

## 5. 求解策略

本问题规模较小（10人×6时段×3窗口+3培训场），约束结构清晰，属于可行域充裕的CSP问题。采用**构造性启发式求解**：

1. **培训分配优先**：先将10人按(4,3,3)分配至3场培训，确保容量约束。
2. **AM时段均匀分配**：因AM无培训，全员10人分配至3窗口，按资质白名单分组。
3. **PM时段剩余分配**：扣除培训人员后，将剩余人员按资质分配到各窗口。
4. **验证所有约束**：程序化校验全部19条需求。

### 5.1 复杂度说明

- 变量数：10×6×3 + 10×3 = 210 个布尔变量
- 约束数：约60+条（覆盖、互斥、上下限等）
- 等价解空间：由于供给充裕，存在大量等价可行解。本方案为其中一种确定性格局。

---

## 6. 求解结果摘要

| 指标 | 数值 |
|------|------|
| 总分配人-时数 | 60 |
| 窗口分配人-时数 | 50 |
| 培训人-时数 | 10 |
| 每人每天任务数 | 2（均衡） |
| 每人3天总任务数 | 6 |
| 约束违反数 | 0 |

所有REQ1~REQ19均已满足，无约束冲突。
