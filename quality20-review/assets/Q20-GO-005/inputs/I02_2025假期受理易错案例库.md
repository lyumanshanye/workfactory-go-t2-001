# 2025假期受理易错案例库（内部培训素材）

## 案例A：除夕日期认知冲突

### 背景
2025年1月初，集团下属某制造基地生产主管在排班系统中将1月28日（周二）标记为"正常工作日"，安排员工全天值班。主管认为"2024年除夕不是法定假，2025年也应该一样"。

### 员工诉求
3名一线员工向SSC-HA投诉，称1月28日应为春节法定假第一天（除夕），要求按法定假标准核算当日出勤。员工同时表示，如果当日被安排值班，应按3倍工资计算。

### 冲突点
- 主管依据旧规则（2013版：春节法定假从正月初一开始，除夕非法定假）排班
- 新规（2024修订，2025-01-01施行）已明确除夕（1月28日/腊月廿九）为法定假
- 涉及加班费核算标准差异（法定假3倍 vs 调休日/休息日2倍）

### SSC专员应识别的关键点
1. 依据S02第795号令第二条第一项修改，春节放假4天，含除夕
2. 1月28日为农历腊月廿九（即除夕），属法定假当日，代码HOL_STAT
3. 主管排班须纠正，员工诉求部分成立（当日如值班应按法定假3倍核算）

## 案例B：连续工作超6天红线

### 背景
2025年春节前，集团某物流中心因订单高峰，在系统中排定：1月22日（周三）至1月27日（周一）连续6天工作，1月28日（除夕）至2月4日放假，2月5日（周三）至2月8日（周六）连续4天工作，2月9日（周日）休息。

但部分员工反馈：从1月22日至1月27日已连续6天，虽然中间有春节假期断开，但春节假期后2月5日至2月10日又要连续工作6天（2月5日-10日），且2月8日为调休上班日。

### 另一场景
某技术团队排班：1月20日至1月27日连续8天工作（含1月25日周六、1月26日周日调休上班日），然后1月28日-2月4日放假。员工质疑1月20日至1月27日连续工作已超过6天。

### 冲突点
- 新规第七条明确"连续工作一般不超过6天"
- 部门以"生产需要""项目紧急"为由排定超长连续工作
- 员工援引新规要求调整排班
- 部门认为"个别特殊情形"可以豁免，但未走审批流程

### SSC专员应识别的关键点
1. 系统应对连续工作≥6天的排班自动预警（HOL_EXCEP）
2. 2级主管须确认是否需要调整排班
3. 如部门主张"特殊情形"需豁免，须升级至3级HRBP审批
4. 不得在未经审批的情况下允许连续工作超过6天

## 案例C：清明节气日期误解

### 背景
2025年3月，有员工咨询SSC-HA："今年清明节是哪天？我看日历上写的是4月5日。"原因是部分手机日历APP显示"清明"节气为4月5日，而国办通知明确4月4日放假。

### 另一场景
某部门助理在填报考勤系统时，将4月5日（周六）标记为"清明节法定假"，而将4月4日（周五）标记为"正常工作日"。导致4月4日值班的员工无法获得法定假加班费。

### 冲突点
- 清明法定假依据"农历清明当日"（即节气当日）
- 不同来源的节气时间可能有1天偏差（4月4日vs4月5日）
- 国办通知已明确2025年清明为4月4日（周五）
- 法定假当日（4月4日）与调休/休息日（4月5日周六、4月6日周日）的核算口径不同

### SSC专员应识别的关键点
1. 依据S12核对表，2025年清明节气对应公历4月4日
2. 法定假当日为4月4日（HOL_STAT），4月5日-6日为周末休息日
3. 系统标记须以国办通知和S12核对表为准，不采纳第三方日历APP数据
4. 清明法定假仅1天（4月4日），非3天全为法定假
