# 5分钟现场观察短讲大纲

> **讲者**：科研管理处培训负责人
> **听众**：即将首次前往研究现场执行观察任务的非临床行政干事
> **时长**：约5分钟
> **目标**：让行政干事在出发前明确自身定位、观察边界、核心动作和上报路径

---

## 第一步：为什么需要你们去现场（定位说明，约1分钟）

**核心信息**：你们是"程序合规的记录仪"，不是"医学科学性的审查员"。

- 科研管理处安排行政干事到现场观察，目的是核查知情同意过程是否按规定程序执行——研究者有没有经过培训？有没有用正确版本的知情同意书？有没有给受试者足够时间理解？
- 你们不评价研究方案的科学性，不判断诊疗方案是否合理，不介入研究者与受试者之间的专业讨论。
- 两办法（2016年原卫生计生委11号令和2023年多部门联合办法）在知情同意核心程序上的底线要求是一致的：经培训的研究者负责获取、逐项说明、给予充分时间、自愿签署。无论你们去的是医院、高校还是科研院所，这些程序底线都适用。
- **你们存在的价值**：通过独立的第三方旁观，帮助机构发现程序漏洞，保护受试者权益，也保护研究者自身。

---

## 第二步：现场只看什么、不看什么（边界划定，约1分钟）

### ✅ 你可以做的

| 动作 | 具体说明 |
|:---|:---|
| 查文件 | 核对授权分工表、培训证书、知情同意书版本号、伦理批件有效期、利益冲突申明表 |
| 旁观过程 | 征得双方同意后，在不干扰的位置旁观知情同意谈话，观察行为动作 |
| 看设备 | 查看录音录像设备是否开机、存储是否正常（不操作、不回放） |
| 记事实 | 用"我看到/我听到"句式，客观记录你观察到的具体行为 |

### ❌ 你绝对不能做的

| 禁令 | 原因 |
|:---|:---|
| 打断谈话 | 你的介入可能影响受试者的自主判断 |
| 翻阅病历 | 超出权限，涉及患者隐私 |
| 评价诊疗方案 | 你不具备医学判断资质，评价即越权 |
| 替代研究者回答受试者的医学问题 | 可能导致错误信息传递 |
| 记录受试者姓名、面部特征等可识别信息 | 违反个人信息保护要求 |
| 操作或回放录音录像 | 涉及受试者隐私 |

**一句话记住你的角色**：只看程序、不看医学；只记行为、不记隐私；只报异常、不当场纠正。

---

## 第三步：怎么观察知情同意（实操要点与典型场景，约2分钟）

### 到达现场后的标准开场白

> "您好，我是科研管理处的[姓名]，今天受伦理委员会委托来观察知情同意的执行过程。我只关注程序方面的事项，不会干预您和受试者的沟通。需要先看一下研究者的授权文件和培训记录，方便吗？"

**要点**：
- 表明身份和来意，降低研究者的防备心理
- 强调"程序观察"定位，明确不干预沟通
- 先提文件核查请求，再提出旁观请求
- 如受试者对旁观表示顾虑，应礼貌退出观察区，仅做文件核查

### 旁观知情同意时重点看三件事

1. **看时间**：研究者递交知情同意书后，是否留出了让受试者安静阅读的时间？还是递完就催着签字？
2. **看动作**：研究者是否拿着知情同意书逐项说明？还是笼统说一句"您看看签个字"？受试者有没有翻阅、提问的动作？
3. **听关键词**：研究者有没有提到"随时可以退出""不影响后续治疗""您的信息会保密"？

### 典型违规场景及应对

**场景一：受试者犹豫时被催促签字**

> 你观察到：研究者说"没什么问题的话就签了吧，后面还有患者等着"，受试者面露犹豫但开始拿笔。

**你应该怎么做**：
1. **不打断**：此时你不是审查员，不当场纠正研究者
2. **默默记录**：在核查表B-02项"异常情况记录"栏写下客观事实——"约[时间]，研究者说出'没什么问题的话就签了吧，后面还有患者等着'，受试者犹豫后签字"
3. **观察结束后反馈**：观察结束后，私下告知研究者"我注意到今天时间比较紧凑，后续可以适当多给一些考虑时间"——这只是善意提醒，不是正式判定
4. **上报**：在核查表异常汇总栏如实记录，提交科研管理处。是否构成正式违规由伦理委员会判定

**场景二：发现非授权人员代为执行知情同意**

> 你观察到：实际与受试者沟通并让其签字的人，不在你刚才核对的授权分工表名单上。

**你应该怎么做**：
1. **记录**：该人员的姓名/工号、其实际行为（沟通、递笔等）
2. **上报**：此情形触发严重违规上报（E-03），当日电话报告伦理委员会主任委员，并书面补报
3. **不干预**：不当场宣布"你没有资格做这个"，也不要求中止该次知情同意过程

## 第四步：发现问题怎么报（上报路径，约1分钟）

### 一般程序异常（中度）

- 如：知情同意书版本与批件不一致、未提供联系方式、利益冲突申明缺失等
- **处理方式**：在核查表上如实记录，观察结束后24小时内书面报告科研管理处负责人
- **不要求**当场纠正

### 严重违规（立即中止观察并直报）

以下情形发现一项即触发：

| 违规类型 | 你的动作 |
|:---|:---|
| 代签字（非受试者本人或法定监护人签署） | 记录时间、人员 → 当日电话直报伦理委员会主任委员 → 书面补报科研管理处 |
| 胁迫或利诱受试者（如"不参加就没法继续治疗"） | 记录原话 → 当日电话直报伦理委员会主任委员 → 书面补报科研管理处 |
| 未经培训/授权人员执行知情同意 | 记录人员信息 → 当日电话直报伦理委员会主任委员 → 书面补报科研管理处 |

**关键原则**：
- 你负责**发现和记录**，不负责**判定和处置**
- 严重违规当天必须电话报告，不能等到写周报
- 报告时用事实描述（"我看到某人代签"），不用主观定性（"这是违法行为"）
