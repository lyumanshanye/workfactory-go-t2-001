# Request for Quotation: HTS Automation System
**Client:** NovaBio Therapeutics
**Project:** Cell Bank High-Throughput Screening & Compound Array
**Date:** 2024-05-15

## 1. Core Technical Requirements
- **Liquid Handling:** Must integrate both contact-based (air displacement) for buffers/reagents and non-contact acoustic liquid handling for compound dispensing.
- **Throughput & Format:** Must support standard 96-well and 384-well microplates.
- **Precision:** CV ≤ 5% in the 10-1000 µL volume range.
- **Cleanroom Compatibility:** Equipment must operate in an ISO 7 (Class 10,000) cleanroom. Must comply with ISO 14644-1 for particulate emission. Exhaust interface must adapt to existing FFU (Fan Filter Unit) downflow.
- **Software Integration:** Must provide REST API supporting POST/GET operations for LIMS integration.

## 2. Project Timeline
- **PO Target:** June 2024
- **Installation & OQ/PQ:** Must be completed by Q3 2024 (September 30, 2024).

## 3. Vendor Submission Requirements
- Detailed technical compliance matrix.
- Pricing workbook including hardware, software, installation, and any required cleanroom adapters.
