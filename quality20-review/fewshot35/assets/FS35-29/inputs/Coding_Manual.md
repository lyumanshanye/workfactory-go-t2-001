# 社区适老服务定性编码手册 V1.0

## 1. 主题与子主题定义
- **T1: 物理环境障碍 (Physical Environment Barriers)**
  - S1.1 楼梯/坡道/无障碍设施缺失
  - S1.2 室内照明/防滑/扶手缺失
- **T2: 数字技术排斥 (Digital Exclusion)**
  - S2.1 界面复杂/认知负荷过高
  - S2.2 缺乏指导/学习渠道
  - S2.3 安全担忧/防骗意识导致的排斥
- **T3: 社会支持网络 (Social Support Networks)**
  - S3.1 邻里互助/非正式网络
  - S3.2 社区工作人员/正式服务
  - S3.3 家庭支持/代际反哺

## 2. 编码规则
- **互斥原则**：同一句话原则上只归入最核心的一个子主题。若明显包含两个独立维度的诉求，需拆分为多行编码。
- **置信度评估**：表述清晰明确为1.0；表述模糊或需推测为0.5-0.8；完全偏离主题或无法判定为0.0。
- **反例处理**：若受访者表现出‘主动技术排斥’（如因极度担心被骗而拒绝使用），应归入 S2.3，但必须在备注中标注‘[反例-主动排斥]’，以区分被动的能力不足。
- **多重编码**：若一段话同时提及物理障碍和他人帮助，需拆分为两行，分别赋予T1和T3代码，并在备注中说明‘[多重编码-交叉]’。
