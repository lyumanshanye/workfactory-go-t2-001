1Replication Package for “Dissecting Mechanisms of Financial Crises: Intermediation and Sentiment”

2Arvind Krishnamurthy and Wenhao Li

4This folder contains the whole replication package for “Dissecting Mechanisms of Financial Crises: Intermediation and Sentiment”, by Arvind Krishnamurthy and Wenhao Li.

5The package will generate all the figures and tables in the paper. Figures are stored in the “Figures” folder, and

7Computational Requirements

8Software requirement:

9R version 3.5.1 (2018-07-02) -- "Feather Spray"

10RStudio 2023.12.1+402 "Ocean Storm" Release

11MATLAB 2023b

12Computational platforms

13All codes are tested on a Macbook Pro 2021, with 8-Core Intel Core i9 and processor speed of 2.3 GHz.

14Time requirement

15There are two main files, one for R, and the other for Matlab.

16Main_step1.m: it takes about 2 minutes.

17Main_step2.R: it takes about to 20 minutes to finish.

18Main_Step3.do: it takes about several seconds.

19If you really want to start from scratch, you can run “run_calibration.m”, which will run the model calibration and simulation data generation. It will take a couple of days to finish.

21Data Availability Statement

22Figure 1 directly comes from Krishnamurthy and Muir (2024).

23Figure 2 uses data on crisis depth from Krishnamurthy and Muir (2024). The data are in the file “Figures/figures_from_data_of_Krishnamurthy_and_Muir/Histogram data.xlsx”, and instructions to generate the histogram is also in that excel file.

25Other data files are generated by model simulation. In Main_Step1.m, you will get all raw model simulated data by running the line

26run("generate_simulation_results_to_excel.m")

27The R file “Model/Analyze_simulations.R” will combine the excel files generated by the above Matlab codes, into “diagnostic_full_yearly.dta” and “bayesian_full_yearly.dta”. These two Stata files then are used by Stata in “Main_step3.do” to generate relevant figures.

29Instructions for Data Analysis

30Here is how to replicate all the results in the paper. Three steps:

31First, run “Main_step1.m”.

32Second, run “Main_step2.R”.

33Third, run “Main_step3.do”.

34The first two files will automatically detect current file path, so you don’t need to change them. In the third one, “Main_step3.do”, you need to change the path so that it sets to “Replication Package/Model/simulated data”.
