3决策依据与可授权范围

4两条各10万年的模拟路径支持对模型内部统计和可观测预警变量的复核，不能代表真实市场历史样本。中介净值约束与预期机制共同改变风险溢价及危机发展，跨模型校准参数并非完全相同，故拟合优劣不是单一预期机制的因果识别。危机发生率接近4%由月度阈值定义机制约束，不能作为独立预测成功。真实外部验证需要获准数据、现实危机标签、可观测性映射和治理监控。

11独立复算与原作者结果对账

12工作簿 IndependentStatistics 给出危机后3年GDP与当期危机交互项回归、资本超额收益关系、危机前利差关系、不同窗口的低利差离散边际效应、信贷连续边际效应和原始Step3 probit；OLS/GLM标准误采用5阶Bartlett Newey-West估计。作者口径与严格前瞻口径分列，效果量与系数不混用。采用严格非重叠9年事件窗口作事件统计稳健性，并以年度信贷/GDP收缩超过10%作经济意义明确的替代事件定义；后者是分析者敏感性，不是作者月度危机重构。TableA1逐项对账见AuthorA1Reconciliation；高于数值容差的差异须作为版本或源输出问题保留，不能强行调整输入以匹配。

13S01 Main_Step3.do：crisis3y uses t,t+1,t+2; partial terminal horizons left at zero unless an observed crisis occurs. This differs from strict future t+1..t+3. Report both conventions; omit censored terminal records for prospective labels.

14S02 Model/Codes_Model/preprocessing_simulation_data.R::gen_crisis：Monthly threshold tuned to 4% annual crisis frequency; gen_non_clustered_crisis condition is index-crisis_last<0*12. Frequency is a definition/calibration choice; code does not enforce advertised 3-year non-consecutive crises.

15S03 Model/Codes_Model/preprocessing_simulation_data.R::processing_simulation_data：credit_growth_past_year uses lag 12 on annual table; GDP/credit forward-growth tails are padded zeros. Variable name is misleading (12 years); omit undefined tails for new calculations.

16S04 Model/Analyze_simulations.R::Table3 Panel C：Regression uses before_crises (one-year-before); output note says five-year-before. Reconcile model code/label and separately estimate a stated prospective five-year definition.

17S05 Model/Analyze_simulations.R::Table3 Panel D：Source computes 3-period window including t while table heading/footnote says next five years; froth is current spread below full-path median. Distinguish replication from prospective warning validation and retrospective threshold estimation.

18S06 Model/Analyze_simulations.R::regs_data：Empirical comparator coefficients are assigned constants to model regression objects (e.g.18.0/2.8). No underlying empirical estimation sample in these objects. May cite author/literature comparator; cannot label independently reproduced real-data regressions.

19S07 Model/Codes_Model/gen_basic_definitions (within preprocessing_simulation_data.R); solve_for_states_from_cs_and_lvg.m：Statistical credit spread is divided by full-path SD; policy-state routines divide equilibrium spread by simulated mean. Policy target cs=1 denotes mean-normalized spread, not one SD or 1% spread.

20S08 Model/Codes_Model/irf_rational_and_behavioral_w_and_lambda.m：Intervention changes w to 1.1*w; deterministic branch bank_credit_impulse uses ratio of xK (leverage), not full bank credit balance. Do not describe this variable as realized credit growth or a capital-ratio regulation effect without reconciling definition.

21S09 Model/Codes_Model/solve_for_states_from_cs_and_lvg.m; irrational_lambda.m：Match leverage and mean-normalized spreads first; solve nonlinear w/believed lambda; diagnostic case maps believed lambda back to underlying with reference and lag parameters. Residual/bounds checked in author code. Same observed leverage/spread does not imply same w, beliefs or underlying state; changing theta at fixed state is not comparable policy evidence.

22S10 Model/solutions/baseline_rational.mat,baseline_behavioral.mat：Serialized core grids contain p/kappap/credit_spread/par but not full post-processed leverage grids or counterfactual trajectories. Source review supports policy mechanism audit; current independent reference does not reproduce equilibrium/recapitalization paths.

23S11 Model/Codes_Model/preprocessing_simulation_data.R; Model/Analyze_simulations.R：capital_excess_return_normalized scales by its sample mean to 0.059; table note describes matching standard deviation. Audit implementation separately from economic comparability; cannot infer a matched return volatility solely from the note.

24政策可比性与准入条件

25作者政策状态匹配同时使用杠杆与按均值标准化的利差，通过插值和非线性求解确定w和信念强度，并对诊断性模型逆向映射 underlying lambda；必须检查网格支持、边界和残差。当前保存的核心解矩阵不足以直接宣称已重算完整政策冲击。资本注入在代码中以w×1.1表达，其冲击不是直接把监管资本比率增加10个百分点；同状态改预期参数也不能替代同可观测状态的跨模型比较。准入条件：冻结统一版本、修订使用说明与变量定义、验证所有前瞻和时点边界、取得独立市场数据与危机标签、进行预先登记的真实时间外推评估和模型风险审查，完成政策路径独立复核后再讨论定量政策授权。
