        <h3>Filter Syntax</h3>
        <p>
          The API uses the Elastic Search
          <a
            href="https://www.elastic.co/guide/en/elasticsearch/reference/current/query-dsl-query-string-query.html#query-string-syntax"
            target="_blank"
            rel="noopener"
            >query string syntax</a
          >
          for filtering. Some notes on the filter syntax include:
        </p>
        <ul class="swagger-ui opblock-body">
          <li>
            To match a phrase, use double quotes:
            <pre><code>NAME:"First Bank"</code></pre>
          </li>
          <li>
            To exclude a phrase or value:
            <pre><code>!(STNAME:"Virginia")</code></pre>
          </li>
          <li>
            The "AND" and "OR" operators can be used to combine filters:
            <pre><code>NAME:"First Bank" AND STALP:IA</code></pre>
            <pre><code>NAME:"First Bank" OR NAME:"Unibank"</code></pre>
            <pre><code>!(BKCLASS:NM OR BKCLASS:N)</code></pre>
          </li>
          <li>
            Dates must be entered in "yyyy-mm-dd" format:
            <pre><code>DATEUPDT:2010-01-25</code></pre>
          </li>
          <li>
            Ranges can be expressed with "[]" (inclusive) or "{}" (exclusive),
            using "*" for an open ended range
            <ul>
              <li>
                Date range that includes 2010-01-01 and 2010-12-31:
                <pre><code>DATEUPDT:[2010-01-01 TO 2010-12-31]</code></pre>
              </li>
              <li>
                Date range that includes only dates between 2010-01-01 and
                2010-12-31:
                <pre><code>DATEUPDT:{2010-01-01 TO 2010-12-31}</code></pre>
              </li>
              <li>
                Number range including institutions with domestic deposits under
                10,000 ($thousands)
